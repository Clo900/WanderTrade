艾尔希亚跑商 单机版
====================

本目录已与在线版的当前核心玩法同步，并固定使用浏览器本地存储：

- 包含最新的地图、交易、事件、任务、载具、状态容器和事件订阅机制。
- 不连接 PowerShell 服务端，不会访问 /api 接口。
- 账号、存档、排行榜和聊天记录均保存在当前浏览器的 localStorage 中。

启动方法
--------

直接双击 index.html，或将它拖入现代浏览器中打开。

目录中的 src/ 是游戏运行所需模块，请勿只复制 index.html；分发单机版时应复制整个“单机版”目录。

存档提示
--------

清理浏览器站点数据、使用隐私模式或更换浏览器会导致本地存档不可用。升级或迁移前，建议先保留整个旧版本目录并避免清理浏览器数据。
