艾尔希亚跑商 · 单机版（v7.2）
==============================

【这是什么】
本文件夹是《艾尔希亚跑商》的【单机版】——不含在线/服务器代码，
直接双击 index.html 即可在浏览器中游玩，账号与存档保存在本机浏览器的
localStorage 中（换浏览器/清缓存会丢失存档，请注意备份）。

【如何游玩】
1. 双击 index.html（或拖入任意浏览器打开）
2. 注册一个本机账号 → 进入游戏
3. 玩法：购买基础物资 → 接取任务 → 前往目的地 → 完成任务 → 卖出物资

【与在线版（服务器版）的区别】
- 单机版：无需服务器，数据全在本机，库存按本地游戏日刷新
- 在线版（项目根目录 server.ps1）：多玩家共享世界（价格/天数/公共事件一致），
  每人库存独立、按服务器游戏日同时刷新，账号存档由服务器保管

【文件清单】
- index.html         游戏本体（含全部代码）
- README.txt         本说明

【提示】
- 建议使用 Chrome / Edge 等现代浏览器
- 本文件夹为独立副本，修改它不会影响根目录的在线版
- 在线版相关文档见上级目录：跑商网页游戏设计文档.md
