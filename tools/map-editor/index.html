工具栏

把「城市」卡片拖到地图地块上新建城市；点「地形」切到 3D 地形模式。

属性编辑

地图
拖动城市即可修改坐标。虚线表示隐藏道路，淡色表示禁用道路。
六角网格
仅绘制完整的平顶六角格。滚轮缩放；按住鼠标中键拖动地图。
城市
道路
地形刷（3D 预览）
尚未选择任何笔刷字段：请先在下面选择「地形 / 地貌 / 山体 / 水路」中的至少一项，否则左键点击不会改变地形。
当前笔刷
在 3D 预览里按住左键拖拽即可连续涂刷（快速拖动会自动补格），松开后统一重建一次；右键 / 中键 / Shift+左键拖动＝旋转 / 平移，滚轮＝缩放。刷笔大小 1 为单格，每加 1 向外扩一圈。
批量规则
规则按「生成后的地形」批量命中，优先级低于逐格覆写，且计入 revision。
山脉
只换山脉分布与形态，不改水 / 草 / 田 / 林 / 花的占比与逐格分布。

本编辑器可脱离游戏独立运行。可选择或拖入 world-map.json，编辑后先校验再导出。通过项目的 start-map-editor.bat 启动时，还可将结果直接安装到项目。地形模式复用 hex-map-lab 的 3D 引擎做所见即所得预览。
