# 艾尔希亚跑商 · 内测开服说明

> 版本：内测开服包 20260902（v9.14.2 星陨城排期修复）　|　对应源码 v9.14.2（成就 / 称号内容扩充 + 反作弊加固 + 星陨城排期对齐）
> 适用：本机单服 / 局域网联机 / 少量互联网联机（百人量级内测）

本包即"开服包"，包含 **服务端 + 网页客户端 + 全新物价种子 + 文档**，不含任何运行数据
（`world.json` / `players/` / `chat.json` 等由服主**首次启动时自动生成**）。
拿到本包后**不要**把旧内测服务器的 `world.json`、`players/` 拷进来——那样会让新服沿
用旧世界时间轴与旧玩家数据，而不是全新开服。

## 三、快速开服

1. 安装 Node.js 18+（https://nodejs.org，一路下一步）。
2. **本机开服**：双击 `start-server.bat`（或 `node server\index.mjs`），
   浏览器打开 http://localhost:8080 注册账号即可。
3. **局域网联机**：
   - 主机：右键 `setup-admin.ps1` → 以管理员身份运行（仅一次，放行防火墙）；
     运行 `node server\index.mjs -Lan`，把打印的地址（如 http://192.168.3.28:8080）发给玩家；
   - 玩家：同一网络下用浏览器打开该地址 → 注册账号 → 进入同一世界
     （价格/天数/公共事件全服一致，库存每人独立）。
4. 换端口：`node server\index.mjs -Port 9090`（需重新以管理员运行
   `setup-admin.ps1 -Port 9090`）。
5. 首次启动控制台会打印 `ADMIN PASS: xxxxxxxx`（GM 管理密码，也可查看 `world.json` 的
   `adminPass`，改后重启生效）。请妥善保管，拥有密码即可发钱/改世界/发全服邮件。

> **⚠ 花生壳 / IPv6-IPv4 绑定注意事项（重要）**
>
> 本包 `start-server.bat` 默认以 **`-Bind 127.0.0.1`（IPv4 回环）** 启动，专为"本机 + 花生壳
> 内网穿透"场景：花生壳映射填 **内网主机 `127.0.0.1`、内网端口 `8080`、协议 HTTP**。
>
> 若改用手动启动 `node server\index.mjs`（不带参数），在部分机器上 Node 会把默认 `localhost`
> 解析为 IPv6 的 `::1`，服务只监听 `::1:8080`——本机浏览器能打开，但花生壳（走 IPv4 连
> `127.0.0.1`）会报 **"内网连接失败，检查 IP 和端口"**。请按需显式指定监听地址：
> - 本机 / 花生壳（与花生壳客户端同一台电脑）：`node server\index.mjs -Port 8080 -Bind 127.0.0.1`
> - 局域网直连（让其它电脑访问本机 IP）：`node server\index.mjs -Lan -Port 8080`
> - 验证是否监听在 IPv4：`Get-NetTCPConnection -LocalPort 8080 -State Listen`，
>   `LocalAddress` 应显示 `127.0.0.1`（或 `0.0.0.0`），而不是只有 `::1`。

## 四、GM 常用指令（在线版需 `password`）

```
/gm <密码> timescale 0.1~100        调整世界时间流速
/gm <密码> setday <天数>            设置世界天数（Day 意外回 1 的恢复手段）
/gm <密码> givegold <玩家> <金额>   给指定玩家发钱
/gm <密码> giveitem <玩家> <物品id> <数量>
/gm <密码> broadcast <消息>         全服跑马灯公告
/gm <密码> starfall start|end|next|status|cycle <建设h> <间隙h>
/gm <密码> titles                   列出全部称号 id
/gm <密码> mail <玩家> [金币] [合金] [称号id] ["标题"] ["正文"] [发件人]
/gm <密码> mailall [金币] [合金] [称号id] ["标题"] ["正文"] [发件人]
```

示例：`/gm <密码> mailall 5000 2 sf_participant "全服感谢" "感谢参与本轮内测！" "运营团队"`

## 五、备份与重置

- 停止服务器请按 **Ctrl+C** 优雅退出（内存态 + 防抖落盘，强制杀进程可能丢最后几秒变更）。
- 备份 = 复制 `world.json` + `players/` 整个文件夹 + `chat.json`（停机时备份）。
- **重置世界**：停止服务器 → 删除 `world.json` 与 `players/` → 重新启动，
  世界按包内 `default-world.json`（全新物价种子）从 Day 1 开始，旧玩家全部清空。
- 删除 `default-world.json` 会丢失物价种子（服务器将回退由客户端重建世界），请勿删除。

- 建议仅邀请熟人，暂不公开到公网；GM 密码不要泄露。

  内测期仍建议仅邀请可信玩家。

  删除会被服务器内存缓存写回复活）。
