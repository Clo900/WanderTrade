  艾尔希亚跑商 · 部署上线指南（统一客户端入口）
  适用：局域网联机 / 互联网联机 / 后台指令 / 弹幕聊天室

【一、项目文件说明】
  运行项目 = 服务器端 + 网页端（全部在本文件夹内）：

    server/                Node.js 服务端（index.mjs 入口 + 17 个模块，零 npm 依赖）
    start-server.bat       一键启动脚本（双击即可，需 Node.js 18+）
    setup-admin.ps1        局域网联机前需【管理员】运行一次（放行防火墙入站端口）
    Online-Client/         唯一客户端目录（在线 / 单机共享）
      index.html           唯一游戏入口
      src/app/runtime.js   运行模式与能力判定（必须保留）
      styles/              静态样式：theme.css（主题变量）/ app.css（布局组件）（必须保留）
    default-world.json     世界种子（13 城价格/限额，勿删除，删了世界重建）
    world.json             运行中的世界数据（服务器自动生成，含 GM 管理密码）
    players/               玩家存档目录（每个账号一个 json）
    chat.json              弹幕聊天室记录（服务器自动生成，保留最近 200 条）
    starfall_activity.json 星陨城活动状态（服务器自动生成）
    starfall_log.txt       星陨城运维日志（结算/轮转/管理操作）
    logs/                  服务器运行日志（v9.14.5 起自动生成，按天 jsonl：
                           gold-consumption-<日期>.jsonl 金币消费审计流水 /
                           error-<日期>.jsonl 服务端错误；可随时删除，重启自动重建）

  单机模式：直接打开 Online-Client/index.html。file:// 会自动进入单机模式，
  不连接 /api，账号与存档保存在当前浏览器 localStorage。
  不要只复制 index.html；必须连同 Online-Client/src/ 与 Online-Client/styles/
  一起分发。

  注意：服务端需要 Node.js 18 或更高版本（https://nodejs.org）。
  服务端采用内存态 + 防抖落盘：停止服务时请按 Ctrl+C 优雅退出，
  避免强制杀进程丢失最后几秒的未落盘变更。


【二、快速启动（本机游玩）】
  1. 安装 Node.js 18+（https://nodejs.org，一路下一步即可）
  2. 双击 start-server.bat（或运行：node server\index.mjs）
  3. 浏览器打开：http://localhost:8080
  4. 注册账号 → 进入游戏
  服务器启动时自动创建世界（13 城），无需任何额外操作。


【三、局域网联机（同一路由器/同一内网）】
  适用：办公室、宿舍、家庭 Wi-Fi 下，几十台电脑一起玩（百人量级）。

  服务器电脑（主机）：
  1. 右键 setup-admin.ps1 →【以管理员身份运行】（弹 UAC 点"是"，只需一次）
  2. 启动服务器：node server\index.mjs -Lan
     （窗口会打印局域网地址，例如 http://192.168.3.28:8080）
  3. 如 Windows 防火墙弹窗 → 勾选"专用网络"→ 允许访问
  4. 把地址发给其他玩家（如 http://192.168.3.28:8080）

  玩家电脑：
  1. 确保与服务器在同一网络（同一 Wi-Fi / 插同一路由器）
  2. 浏览器打开服务器地址（如上）
  3. 注册自己的账号 → 进入同一个世界
     （价格/天数/公共事件全服一致；库存每人独立、随游戏日同时刷新）

  查本机 IP 方法：Windows 开始菜单 → 输入 cmd → 运行 ipconfig
  → 找"IPv4 地址"（如 192.168.x.x）。

  常见问题：
  - 玩家打不开 → 检查是否同一网络；检查防火墙是否放行（步骤 1/3）；
    临时方法：服务器电脑防火墙关掉专用网络再试（玩完记得开回来）。
  - Node 服务端无需管理员权限即可监听端口，也不再需要注册 URL ACL；
    唯一的"Access is denied"来源是防火墙未放行。


【四、互联网联机（不同网络/异地）】
  方案 A：路由器端口转发（有公网 IP 时）
    1. 用管理员运行 setup-admin.ps1 一次（放行防火墙）
    2. 用 -Lan 启动服务器：node server\index.mjs -Lan
    3. 登录路由器管理页（浏览器打开 192.168.1.1 或看路由器背面标签）
    4. 找"端口映射/端口转发/虚拟服务器"功能
    5. 添加规则：外部端口 8080 → 内部 IP(服务器电脑) → 内部端口 8080
       （协议 TCP；保存并重启路由规则）
    6. 查自己公网 IP（浏览器搜"IP"即可看到）
    7. 玩家访问：http://你的公网IP:8080
    注意：运营商可能屏蔽 80 端口；8080 一般可用。
    若路由器不支持或没有公网 IP，用方案 B。

  方案 B：内网穿透工具（无公网 IP，推荐新手）
    原理：把家里的 8080 端口通过第三方服务映射到公网域名。

    B-1 花生壳（国内，图形界面，适合新手）
      1. 官网 oray.com 注册账号并下载"花生壳"客户端
      2. 登录后添加"内网穿透"：协议 HTTP、内网主机 127.0.0.1、端口 8080
      3. 得到公网地址（如 http://xxxx.gicp.net:端口）
      4. 玩家访问该地址即可
      免费额度通常够用；宽带要求上行 ≥ 2M。

    B-2 frp（免费开源，需一台有公网 IP 的服务器，如云主机）
      服务器端（云主机，Linux）：
        wget frp 最新版，解压后编辑 frps.toml：
          bindPort = 7000
          [webServer] 按需开启（用于面板查看）
        运行：./frps -c frps.toml
      本机（Windows）：
        下载同版本 frp 客户端 frpc.exe，编辑 frpc.toml：
          serverAddr = "云主机公网IP"
          serverPort = 7000
          [[proxies]]
          name = "trade"
          type = "tcp"
          localIP = "127.0.0.1"
          localPort = 8080
          remotePort = 8080
        运行：frpc.exe -c frpc.toml
        玩家访问：http://云主机公网IP:8080

    B-3 其他工具：ngrok（免费隧道）、Tailscale/ZeroTier（组虚拟局域网，
      装好后玩家直接访问你的局域网地址，相当于异地局域网）。

  面向百人同时在线的建议：服务端实测 100 并发下 ~68 req/s、p95 延迟约 1ms，
  一台普通 PC 即可支撑；若长期公网运行，建议服务器电脑保持 8GB 内存以上、
  定期备份数据、并考虑将 players/ 目录放到固态硬盘。


【五、日常运维】
  启动 / 停止：
    - 启动：双击 start-server.bat 或 node server\index.mjs [-Lan]
    - 停止：在服务器窗口按 Ctrl+C（优雅退出，自动全量落盘，请勿强制杀进程）
    - 端口更换：node server\index.mjs -Port 9090
      （玩家访问地址相应变为 :9090；setup-admin.ps1 也已带 -Port 参数，
        换端口时需重新管理员运行 setup-admin.ps1 -Port 9090）

  备份 / 迁移：
    - 世界数据：world.json（删掉会按 default-world.json 重建新世界，且世界时间轴重置——所有玩家 Day 回 1、事件按第 1 天）
    - 玩家数据：players/ 整个文件夹
    - 活动数据：starfall_activity.json、starfall_log.txt
    - 备份 = 复制上面这些到安全位置；迁移 = 连同全部文件一起拷贝到新机器
      （注意服务器路径变化后 world.json 自动延续，无需重新建世界）
    - 备份建议在停机状态下进行（服务端为内存态 + 防抖落盘，运行中备份
      可能拿到最后几秒未落盘的旧数据）
    - Day 意外回 1 的恢复：浏览器控制台执行 GM 指令
      runCmd("/gm <world.json里的adminPass> setday <正确天数>")，全服天数立即恢复

  查看在线状态：
    - 服务器窗口会持续打印访问日志（API 错误 / 星陨城运维日志）
    - 浏览器打开 http://localhost:8080/api/world 可查看世界快照

  并发压测（可选，验证服务器承载）：
    - node scripts\load\load-test.mjs -n 100 -t 30
      （模拟 100 个在线玩家的轮询/存档/交易负载；p95 延迟应 < 500ms）


【六、后台指令系统（GM/作弊）】
  入口：游戏页面右下角 🛠 按钮 → 指令台；或在浏览器控制台输入
        runCmd("/指令")。

  权限说明（v9.11.x）：
    - 单机版：本地调试指令随便使用；/gm starfall|mail|broadcast 免密可用
    - 在线版：普通玩家仅可用查看类（/help /gold /time）与 /gm 通道；
      本地调试指令一律禁用（指令台提示"仅 GM 可用"），GM 通过 /gm <密码> 执行

  查看类指令（单机/在线普通玩家均可用）：
    /help                           查看帮助
    /gold                           查看当前金币
    /time                           查看服务器时间校准状态

  本地调试指令（仅单机版；在线版普通玩家禁用，GM 走 /gm 通道）：
    /addgold <金额>                 给自己加金币
    /addcargo <物品id> <数量>       加货物（grain、salt、ironware…）
    /addmat <类型> <数量>           加材料（gear/repair_kit/fuel_tank/engine/staralloy）
    /repair                         耐久修满
    /core <等级>                    载具核心直升等级
    /wagon <类型> <等级>            装车厢（cargo/pass/balanced/engine）
    /setrep <城市id> <经验>         设置声望经验
    /stock <城市id> <物品id> <数量> 设置自己库存
    /day <天数>                     本地推进天数

  GM 指令（需管理密码，服务器权威执行，全服生效）：
    /gm <密码> timescale <0.1~100>  世界时间流速（1=正式，>1 加速，<1 减速）
    /gm <密码> setday <天数>        设置世界天数
    /gm <密码> givegold <玩家> <金额>  给指定玩家发钱
    /gm <密码> giveitem <玩家> <物品id> <数量>  给指定玩家发物资
    /gm <密码> broadcast <消息>     全服广播
    /gm <密码> starfall start|end|next|status|cycle <建设期h> <间隙期h>  星陨城活动管理
    /gm <密码> titles                列出全部称号 id（发邮件称号附件用；专属称号标注「专属」）
    /gm <密码> mail <玩家> [金币] [合金] [称号id] ["标题"] ["正文"] [发件人]
                                    发邮件给指定玩家（- 跳过参数；金币/合金/称号全空=纯通知邮件）
                                    （专属称号只能通过本指令单独发放，v9.12.0）
    /gm <密码> mailall [金币] [合金] [称号id] ["标题"] ["正文"] [发件人]
                                    发邮件给全体玩家（遍历所有账号投递；全空=纯通知）
                                    （携带专属称号会被拒绝，v9.12.0）

  GM 邮件推荐流程（v9.11.x / v9.12.0）：
    1) 查称号：/gm <密码> titles            → 得到称号 id（如 sf_champion / 星陨城之光；ex_frontier_hero 等为专属）
    2) 单发奖励（金币+合金+称号+自定义文案+发件人）：
         /gm <密码> mail alice 10000 5 sf_champion "活动奖励" "恭喜夺冠！" "运营团队"
    3) 单发专属称号（只给特定玩家，如"边境英雄"）：
         /gm <密码> mail bob - - ex_frontier_hero "特别嘉奖" "感谢你为星陨城做出的贡献！" "边境城建指挥部"
         （专属称号不可用 mailall 群发；未获得前其他玩家面板看不到该称号）
    4) 单发纯通知（无附件，自定义发件人）：
         /gm <密码> mail alice - - - - - "边境城建指挥部"
    5) 全体通知（无附件，自定义发件人）：
         /gm <密码> mailall - - - "停服公告" "服务器将于 15 分钟后维护" "运营团队"
    6) 全体发奖励（可选称号，不可为专属）：
         /gm <密码> mailall 5000 2 sf_participant "全服感谢" "感谢参与内测！"
    说明：标题/正文含空格请用双引号包裹；"-"表示跳过该参数；
         正文换行用 \n 转义（如 "第一行\n第二行\n第三行"）；
         [发件人] 为可选参数（缺省 "GM"，≤20 字符），可增强代入感（如运营团队/边境城建指挥部）；
         纯通知邮件无领取附件（玩家直接阅读，可删除）；
         称号 id 会由服务端对照共享配置表（Online-Client/src/data/title-defs.js）校验，
         未知 id 会被拒绝（防止发错造成"幽灵称号"）。

  GM 管理密码：
    服务器【首次启动】时控制台会打印：ADMIN PASS: xxxxxxxx
    也可以直接查看/修改 world.json 里的 adminPass 字段（改后重启生效）。
    请妥善保管，拥有密码即可给任意玩家发钱/改世界。
    口令只存在于服务器 world.json，不会随 /api/world 下发（v9.14.1 补强）；
    运营者通过聊天框 /gm <密码> 输入执行指令。
    说明：v9.14.1 已上线反作弊四道防线（会话 Token 防冒充越权、存档单调版本号
    sv 防回滚、gs 结构白名单清洗、快照差分审计防异常注入），详见
    Docs/反作弊与存档安全加固.md。残余风险：任务/成就/事件等客户端结算玩法
    的小幅数值伪造无法完全杜绝，内测期仍请仅邀请可信玩家。


【七、成就与排行榜（v7.5）】
  玩家功能（无需配置）：
  - 🏆📊 成就排行：导航"成就排行"页签（排行榜在上、成就面板在下）。
  - 🏆 成就：16 项成就（首单任务、累计收入、卖出件数、旅行里程、
    拜访全部城市、金币里程碑、车厢/核心、声望等级等），达成自动
    解锁并提示，奖励金币与材料。
  - 📊 排行：四榜切换（金币/里程/任务/声望）。在线版为全服实时排名
    （读取服务器 players/ 计算，前 20 名，自己标记"（我）"）；
    单机模式为本机多账号排名。
  - 数据自动统计存档（买入/卖出/任务/里程/访问/声望升级等），
    老玩家存档自动兼容，无需清档。


【八、弹幕聊天室（v7.7）】
  玩家功能（无需配置）：
  - 💬 气泡：页面左下角，可【随意拖动】换位置；点击 → 对话框
    从气泡位置原地展开（气泡隐藏）。
  - 对话框可拖动（按住标题栏移动）；点 ✕ 关闭后重新变回 💬 气泡，
    气泡出现在对话框最后位置。
  - 发言：输入框打字 → Enter 或点"发送"；需先登录账号。
    格式：【玩家id】〈所在地〉：内容（所在地=发言时所在城市）。
  - 弹幕：消息以弹幕形式在网页顶部 25% 区域随机高度从右向左飘过，
    飘出左缘后消失（每条约 8~14 秒）。
  - 历史：点"查看历史"浏览全部消息，每条带现实时间 HH:MM:SS 时间戳。
  - 在线模式为全服实时聊天（消息经服务器 SSE 推流实时送达，断线自动重连，
    连接异常时自动回退 3 秒轮询）；单机模式为本地聊天（仅本机可见）。


【九、时间设定（v7.5 正式）】
  - 游戏日 = 10 现实分钟
  - 中枢周期（价格大调整） = 2 现实小时 = 12 游戏日
  - 城市库存每【现实 30 分钟】刷新一次，每人独立、全服同时刷新
  - 公共事件按中枢周期确定性触发，剩余时间按 分:秒 显示
  - 世界时间流速可由 GM 通过 timescale 指令临时调整（1=正式）


【十、常见问题（FAQ）】
  Q1 玩家打不开网页？
    → 局域网：检查同网段 + 防火墙；互联网：检查映射/穿透是否生效。

  Q2 注册提示"服务器不可用"？
    → 确认服务器进程在运行；确认访问的是服务器地址而非本地文件
      （HTTP(S) 默认在线；file:// 打开 Online-Client/index.html 自动进入单机模式）。
      在线模式不会静默切换存档来源，可在提示页重试或明确选择进入单机模式。

  Q3 两个玩家价格不一样？
    → 正常情况不会发生（共享世界种子）。若发生，检查是否一个
      连了服务器、另一个用 file:// 打开了本地文件。

  Q4 库存被别人买空了吗？
    → 不会。库存每人独立，只共享刷新节奏（30 分钟一次）。

  Q5 GM 密码忘了？
    → 打开 world.json，找到 adminPass 字段，改成新值后重启服务器。

  Q6 改完世界流速/天数，在线玩家什么时候生效？
    → 玩家页面每 60 秒自动同步一次；也可让玩家刷新页面立即生效。

  Q7 密码安全吗？
    → 服务器用 SHA256+盐 存储，且 v9.11.x 起服务端已升级为 Node.js 权威后端
      （交易结算、活动、邮件均服务端权威校验）。v9.14.1 起登录签发会话 Token
      （7 天滑动有效，内存存储），服务器重启后玩家重新登录一次即可；改密码会
      吊销该账号全部旧会话并签发新 Token。内测期建议仍仅邀请可信玩家。

  Q8 换电脑/换浏览器存档会丢吗？
    → 在线模式不会（存档在服务器 players/）；单机模式会（存本机浏览器）。
      单机玩家应使用顶栏“导出”备份 JSON，并在新浏览器通过“导入”恢复。

  Q9 想重置世界？
    → 停止服务器 → 删除 world.json 与 players/ → 重新启动。
      世界将按 default-world.json 全新开始（旧玩家全部清空，谨慎）。

  Q10 发版/更新后玩家需要做什么？
    → 每次发版必须把 server/ 与 Online-Client/ 一起替换（缺一不可）后重启；
      玩家刷新一次页面并按提示重新登录一次（客户端 APP_VERSION 变化会触发
      "仅一次"的强制重登，登录页角落显示当前版本号，可据此核对是否新版）。
    → v9.14.2（星陨城修复）：重启后服务端启动自愈——错位期次（边界未对齐
