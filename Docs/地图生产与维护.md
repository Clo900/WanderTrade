# 地图生产与维护

地图采用“一个人工数据源 + 自动生成运行时快照”的方式维护。策划和开发只修改 `map/world-map.json`，不要直接编辑 `Online-Client/src/data/world-map.generated.js` 或 `default-world.json` 中的 `tradeRoads`。

## 推荐工作流

1. 双击项目根目录的 `start-map-editor.bat`，浏览器会打开本地地图编辑器并自动导入正式地图。
2. 拖动城市或编辑道路，点击“安装到项目”。系统会先校验新地图，将旧地图留档至 `map/archive/`，再替换 `map/world-map.json`、生成客户端快照并同步服务端经济路网。
3. 执行 `node scripts/map/validate-map.mjs` 和 `node --test scripts/map/*.test.mjs`。
4. 打开客户端检查地图、寻路、旅行点和价格距离。

也可使用命令行安装已有地图文件：`node scripts/map/install-map.mjs <新地图.json>`。

## 独立编辑器与导入导出

- 独立入口是 `tools/map-editor/index.html`。页面自身不依赖游戏客户端脚本或生成快照，但**地形模式**会以相对路径复用 `hex-map-lab/` 的 3D 引擎（`../../hex-map-lab/src/**` 与 `vendor/three.min.js`），因此：
  - 通过 `start-map-editor.bat` 启动时，服务根目录是**项目根**（`scripts/map/editor-server.mjs`），相对路径可正常解析；
  - 若要单独复制出去使用，需连同 `hex-map-lab/` 一起复制，或只用「地图模式」（城市 / 道路），地形模式会因引擎缺失而不可用。
- 顶部有「地图模式 / 地形模式」切换：地图模式是平顶六角网格上的城市 / 道路编辑；地形模式是 `hex-map-lab` 的 3D 所见即所得预览 + 稀疏覆写编辑。
- 直接双击入口即进入离线模式。点击“导入 JSON”或把地图 JSON 拖入画布，编辑后可执行本地结构校验并“导出 JSON”。
- 编辑画布采用平顶六角网格；可输入横向/纵向格子数量和格子半径，只绘制完整六边形，并可切换网格显示与格心吸附。城市圆点、城市文字和道路节点会随格子半径同比缩放。“全部元素吸附到格心”会同时整理城市、道路控制节点和 Y 形分叉点。
- 地图画布不使用横向或纵向滚动条：滚动鼠标滚轮缩放，以鼠标所在位置为缩放中心；按住鼠标滚轮键拖动可平移视图。
- “六角最短路径连接”依次选择两座城市后，会将端点吸附到格心，并按六角相邻关系生成最少格数道路。路径以 `curve.mode = "hex"` 和中间格心 `hexPath` 保存；移动端点城市或调整网格后会自动重新寻路。
- 选中六角道路后点击“增加弯曲节点”，会出现蓝色途经节点。拖动时节点始终吸附格心，道路在城市与各途经节点之间分段最短寻路，因此弯曲后仍只经过六角格心；双击蓝色节点可删除。
- 页面左侧是两列方形工具栏。将“城市”卡片拖到六角地形块上，会吸附到最近格心并创建带唯一 ID 的新城市；若该格已有城市则拒绝重复创建。
- 切到「地形模式」后，右侧「地形刷」面板用「地形 / 地貌 / 山体风格 / 山体高度 / 水路模式」构成笔刷，在 3D 预览里**按住鼠标左键拖拽即可连续涂刷**（快速拖动会沿六角直线自动补格，同一笔内按格去重）；**右键 / 中键 / Shift+左键**拖动＝旋转 / 平移，滚轮＝缩放。未选择任何笔刷字段时面板顶部会给出醒目提示，此时左键只用于选中查看。刷笔大小 1 为单格，每加 1 向外扩一圈；勾选「擦除覆写」可清除覆写。每笔结束统一重建一次（重建前先显示「正在重建世界…」遮罩），面板会显示重建耗时与覆写格数。为控制重建代价，**编辑期山体只建当前视角需要的那一级**（一次重建约 1s；更细的档位在视角拉近时自动补建一次），地表/植被等程序化贴图按参数缓存、不再重画 —— 实验页与游戏运行时不受影响，仍是完整的多级 LOD。视角默认「**低透视**」，点面板上的「视角」按钮可切到**正交**（等轴测）；两者取景范围一致（`applyRig` 用 `ortho.zoom` 对齐到同一距离下的可见高度），切换不改缩放。
- 「批量规则」按**生成后的地形**批量命中（如「所有山脊 → 隘口」），优先级低于逐格覆写；「山脉」卡片可重掷山脉分布与形态（只换山脉，不改水 / 草 / 田 / 林 / 花的占比与逐格分布）。结果保存在 `terrain.hex.overrides`，随地图导入导出。
- 选中城市后可点击“删除所选城市”。编辑器会显示页面内确认弹窗；确认后会同步删除相连道路、区域成员记录以及以该城市为锚点的地形特征，避免遗留失效引用。
- 网格偏好保存在可选的 `editor.hexGrid` 中并随 JSON 导入导出；游戏运行时会忽略该编辑器元数据。
- 离线模式不会写入项目文件；通过 `start-map-editor.bat` 启动后才会显示“安装到项目”，安装时继续执行完整的服务端经济表与跨文件校验。
- `tools/map-editor.html` 保留为旧入口兼容页，会自动跳转到新的独立编辑器。

## 数据职责

| 字段 | 用途 |
| --- | --- |
| `cities` | 城市坐标、名称、等级、可售商品和所在图层 |
| `roads[].travelDistance` | 寻路、旅行耗时、地图里程标签 |
| `roads[].economicDistance` | 服务端价格距离；构建时同步至 `default-world.json` |
| `roads[].curve` | `auto` 自动弯曲、`straight` 直线、`hex` 六角格心最短路径、`control` 多个可拖拽路径节点、`manual` 两个绝对控制点、`branch` 共享主干的 Y 形分支 |
| `roads[].enabled` | 是否进入旅行和经济路网 |
| `roads[].hidden` | 可通行但不在地图上绘制，便于秘密路线 |
| `terrain` | 地形种子、采样间距、等高线层级、城市平整和锚点地貌；其中 `terrain.hex.overrides` 是六角世界的地形覆写（轴向 `q,r` 稀疏 `tiles` + 按地形批量命中的 `rules`），供 3D 地形模式与 `hex-map-lab` 消费 |
| `regions` / `layers` | 区域分组和多层地图扩展的稳定标识 |

`map/world-map.schema.json` 提供编辑器提示所需的基础 Schema；`validate-map.mjs` 负责跨文件、路网连通性和业务语义校验。

## 扩展约定

- 新增城市时，坐标必须位于 `viewBox` 内，商品 ID 必须已存在于世界价格表。
- 道路 ID 应保持稳定。修改端点时建议同步改成 `<from>-<to>`，但不要在无必要时批量重命名。
- 选中普通道路后点击“增加弯曲节点”，系统会在当前最长路段中插入黄色节点；可反复添加并独立拖动，道路会平滑穿过所有节点。六角道路使用蓝色格心途经节点，并在每段自动重新寻路。双击节点可删除，旅行位置点使用相同路径。
- 编辑器的“生成 Y 形道路”会依次要求选择起点、终点 A、终点 B，并生成两条共享主干和分叉点的普通可寻路道路。两条道路以相同 `curve.group` 组成一组；调整其中一条的分叉点会同步另一条。
- `hidden` 目前只控制可见性，不是解锁状态。未来做动态解锁时，应新增 `unlock` 条件并由用户状态判断，不要改变 `hidden` 原义。
- `layers` 已保留数据结构；当前客户端展示 `surface`。将来增加地下/海域时，应增加明确的图层切换器，再按活动图层过滤城市和道路。
- 地形特征使用城市作为 `anchor`。移动城市后，关联丘陵、山脊和盆地会一起移动，避免重新手调大量绝对坐标。
- 换行规范：`map/world-map.json`、`Online-Client/src/data/world-map.generated.js`、`default-world.json` 入库统一 LF（见根目录 `.gitattributes`）。校验脚本对快照比对已容忍换行差异；若仍报“快照过期”，先 `git add --renormalize .`，再运行 `build-map.mjs`。
- 城市属性（`tier`/`goods`）变更不会自动同步经济表：`install-map` 只同步路网与经济距离。`validate-map` 会拦截“新增城市但 `basePrices/purchaseLimits` 未登记”与“`goods` 与 `purchaseLimits` 不一致”；`tier` 变更请在编辑器确认提示后保存，并同步 `Online-Client/src/core/data.js` 中 `cityStage()` 的白名单与仓库解锁配置。

## 故障定位

- 报“快照过期”：先运行构建脚本，并提交生成文件。
- 报“经济距离未同步”：不要手改 `default-world.json`，运行构建脚本。
- 新配置未在浏览器出现：确认 `world-map.generated.js` 已更新，并同步提高 `index.html` 上地图脚本的缓存版本。
- 提高 `worldSchema` 会触发服务端用默认世界刷新经济配置；仅在需要让已有运行世界采用新路网时提高。
