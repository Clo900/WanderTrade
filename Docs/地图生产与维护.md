# 地图生产与维护

地图采用“一个人工数据源 + 自动生成运行时快照”的方式维护。策划和开发只修改 `map/world-map.json`，不要直接编辑 `Online-Client/src/data/world-map.generated.js` 或 `default-world.json` 中的 `tradeRoads`。

## 推荐工作流

1. 双击项目根目录的 `start-map-editor.bat`，浏览器会打开本地地图编辑器。
2. 拖动城市或编辑道路，点击“保存并安装”。系统会先校验新地图，将旧地图留档至 `map/archive/`，再替换 `map/world-map.json`、生成客户端快照并同步服务端经济路网。
3. 执行 `node scripts/map/validate-map.mjs` 和 `node --test scripts/map/*.test.mjs`。
4. 打开客户端检查地图、寻路、旅行点和价格距离。

也可使用命令行安装已有地图文件：`node scripts/map/install-map.mjs <新地图.json>`。直接双击 `tools/map-editor.html` 时受浏览器权限限制，只支持“仅导出 JSON”。

## 数据职责

| 字段 | 用途 |
| --- | --- |
| `cities` | 城市坐标、名称、等级、可售商品和所在图层 |
| `roads[].travelDistance` | 寻路、旅行耗时、地图里程标签 |
| `roads[].economicDistance` | 服务端价格距离；构建时同步至 `default-world.json` |
| `roads[].curve` | `auto` 自动弯曲、`straight` 直线、`control` 多个可拖拽路径节点、`manual` 两个绝对控制点、`branch` 共享主干的 Y 形分支 |
| `roads[].enabled` | 是否进入旅行和经济路网 |
| `roads[].hidden` | 可通行但不在地图上绘制，便于秘密路线 |
| `terrain` | 地形种子、采样间距、等高线层级、城市平整和锚点地貌 |
| `regions` / `layers` | 区域分组和多层地图扩展的稳定标识 |

`map/world-map.schema.json` 提供编辑器提示所需的基础 Schema；`validate-map.mjs` 负责跨文件、路网连通性和业务语义校验。

## 扩展约定

- 新增城市时，坐标必须位于 `viewBox` 内，商品 ID 必须已存在于世界价格表。
- 道路 ID 应保持稳定。修改端点时建议同步改成 `<from>-<to>`，但不要在无必要时批量重命名。
- 选中普通道路后点击“增加弯曲节点”，系统会在当前最长路段中插入黄色节点；可反复添加并独立拖动，道路会平滑穿过所有节点。双击节点可删除，旅行位置点使用相同曲线。
- 编辑器的“生成 Y 形道路”会依次要求选择起点、终点 A、终点 B，并生成两条共享主干和分叉点的普通可寻路道路。两条道路以相同 `curve.group` 组成一组；调整其中一条的分叉点会同步另一条。
- `hidden` 目前只控制可见性，不是解锁状态。未来做动态解锁时，应新增 `unlock` 条件并由用户状态判断，不要改变 `hidden` 原义。
- `layers` 已保留数据结构；当前客户端展示 `surface`。将来增加地下/海域时，应增加明确的图层切换器，再按活动图层过滤城市和道路。
- 地形特征使用城市作为 `anchor`。移动城市后，关联丘陵、山脊和盆地会一起移动，避免重新手调大量绝对坐标。

## 故障定位

- 报“快照过期”：先运行构建脚本，并提交生成文件。
- 报“经济距离未同步”：不要手改 `default-world.json`，运行构建脚本。
- 新配置未在浏览器出现：确认 `world-map.generated.js` 已更新，并同步提高 `index.html` 上地图脚本的缓存版本。
- 提高 `worldSchema` 会触发服务端用默认世界刷新经济配置；仅在需要让已有运行世界采用新路网时提高。
