# 在线客户端颜色与样式文件表

本文档记录在线客户端 CSS 的文件职责、加载顺序、颜色变量和后续维护边界。

## 当前结构

```text
Online-Client/
├─ index.html
└─ styles/
   ├─ theme.css
   └─ app.css
```

## 文件职责

| 文件 | 职责 | 当前内容 | 维护原则 |
|------|------|----------|----------|
| `Online-Client/styles/theme.css` | 主题颜色与视觉变量 | 页面背景、面板、文字、状态色、城市等级色、圆角、阴影，以及后台面板使用的 `--line`（v9.10.5 清理：`--bg2` 已删除） | 只放主题变量，不放组件布局选择器 |
| `Online-Client/styles/app.css` | 页面布局与组件样式 | 原 `index.html` 主 `<style>`、后台指令台、成就排行、弹幕聊天室，以及 v9.9 起的星陨城活动面板（`.sf-*`）、邮箱弹窗（`.mailbox-*`）、跑马灯公告（`.broadcast-bar`）等全部 CSS | 组件优先使用 `theme.css` 变量，避免新增主题色字面量；新增模块样式仍统一落到 `app.css` |
| `Online-Client/index.html` | 页面结构与运行逻辑 | HTML、内联事件、JavaScript、动态模板 | 不再新增 `<style>` 区块；静态样式通过 `<link>` 加载 |

## 加载顺序

`index.html` 的 `<head>` 中按以下顺序加载：

```html
<link rel="stylesheet" href="styles/theme.css">
<link rel="stylesheet" href="styles/app.css">
```

先加载主题变量，再加载布局和组件样式。`app.css` 可以直接使用 `theme.css` 中的变量。

| 变量 | 用途 |
|------|------|

| `--card` | 内容区、市场卡片、聊天消息背景 |
| `--cardHover` | 卡片悬停和展开背景 |
| `--accent` | 主操作色、按钮、强调边框 |
| `--gold` | 金币、声望、奖励、稀有状态 |
| `--green` | 买入、成功、正常状态 |
| `--red` | 错误、危险状态 |
| `--text` | 主文字 |
| `--text2` | 次级文字 |
| `--text3` | 辅助文字、弱边框 |
| `--buy` | 买入价格和买入操作 |
| `--sell` | 卖出价格和卖出操作 |
| `--travel` | 旅行、情报、网络提示 |
| `--village` | 新手村城市节点 |
| `--town` | 城镇城市节点 |
| `--capital` | 王都城市节点 |
| `--frontier` | 边疆城市节点 |
| `--special` | 特殊城市节点 |
| `--line` | 后台指令台、聊天室边框和分隔线 |

当前 `:root` 与 `[data-theme="light"]` 使用浅色主题，`[data-theme="dark"]` 采用从 `ca95b07` 合并回来的旧深色配色，保留 `data-theme` 入口以支持前端切换。

## 地图专用变量

地图颜色统一以 `--map-*` 命名，定义在 `Online-Client/styles/theme.css`，由 `app.css` 和 `index.html` 中的地图 SVG 共同使用。浅色和深色主题分别提供一组值，切换 `data-theme` 时地图背景、地形、道路、文字、控件和动态装饰会同步切换。

| 变量组 | 用途 |
|------|------|
| `--map-bg-*` | 地图容器的径向光照、线性背景渐变和 SVG 核心光照 |
| `--map-border`、`--map-info-bg` | 地图边框和地图信息栏背景 |
| `--map-contour-*` | 等高线、等高线纹理、呼吸动画和地形发光 |
| `--map-terrain*` | 等高线区域的地形填充透明度 |
| `--map-node-border` | 城市节点描边 |
| `--map-road*` | 道路、道路流动线和道路标签 |
| `--map-city-label*` | 城市名称及文字阴影 |
| `--map-control-*` | 地图缩放/定位按钮及悬停状态 |
| `--map-shield-light`、`--map-mist-*`、`--map-cloud` | 城市光晕、地图雾效和云朵 |
| `--map-travel-dot*` | 旅行中的当前位置点及描边 |

- 顶栏和导航。
- 地图、城市、车站、任务、车厢、市场、仓库和弹窗。
- Toast、事件横幅、情报所聊天。

- 弹幕聊天室。
- 浅/深色主题切换按钮与主题记忆。

## 暂未统一的颜色来源

地图 CSS 和地图 SVG 中原先的固定颜色已在本轮统一为 `--map-*` 主题变量。以下颜色仍保留在 HTML 或 JavaScript 动态内容中：

- 动态模板中的 `style="..."`，例如进度条宽度、任务稀有度颜色和按钮状态色。
- Canvas 价格图表通过 `fillStyle`、`strokeStyle` 使用的颜色。
- 非地图图表、弹幕和其他视觉效果中的硬编码透明色。

这些内容需要结合对应渲染模块单独迁移，不能简单全部替换成页面主题变量。

## 后续维护规则

1. 新增页面颜色优先先添加语义变量，再在 `app.css` 中使用 `var(--变量名)`。
2. 不在 `index.html` 中新增静态 `<style>`；新增组件样式统一写入 `app.css`。
3. 动态颜色如果只表达状态，应优先复用 `--accent`、`--gold`、`--green`、`--red`、`--travel`、`--buy`、`--sell`。
4. 需要支持多主题时，在 `theme.css` 中增加 `[data-theme="主题名"]` 覆盖，不修改组件选择器。
5. 修改 CSS 文件路径时，要同步检查服务器静态根目录和部署包目录结构。
6. 主题切换按钮只改 `data-theme`，不要直接改写整套颜色值。

## 验收清单

- `index.html` 中不存在静态 `<style>` 区块。
- `theme.css` 和 `app.css` 均能通过 `styles/...` 路径加载。
- 页面主背景、面板、文字、按钮和状态色与拆分前一致。
- 地图 CSS 不再直接定义地图背景、地形、道路、标签和控件颜色。
- 地图 SVG 不再直接定义地图渐变、云雾和旅行位置点颜色。
- 后台指令台、成就排行和弹幕聊天室样式仍然存在。
- JavaScript 内联模板和动态渲染逻辑未被修改。
- 小屏顶栏、地图、城市市场和弹窗没有因 CSS 加载顺序发生回归。
- 浅/深色切换后，顶栏和主要组件仍保持可读。
