## 一、模拟口径（重要假设）

| 项目   | 口径                                                                                                       |
| ---- | -------------------------------------------------------------------------------------------------------- |
| 阶段载具 | 新手村 均衡Lv1·30货舱·速4.85；初期 货运Lv2×2+动力Lv2·200货舱·速6.0；中期 货运Lv3×3+动力Lv3·400货舱·速7.5；后期 货运Lv4×4+动力Lv4·600货舱·速9.0 |
| 倒货   | **180 游戏日逐日利润取中位数**（代表"典型一天"收益，突破/极端日不拉高均值）；按**往返**计效（去载货+回空车）                                            |
| 任务   | 送货/送客 50/50 混合（复刻 `rollTask` 数值口径：距离×阶段单价×稀有度 + 按件/按人附加 × 品质 × 时效，v9.7 慢单概率上调）；按**单程**计效                             |
| 时间   | 倒货往返 `2×dist/speed`；任务单程 `dist/speed`（送达即完成，可在目的地再接单）                                                    |
| 目的地  | 倒货=任意城市可卖任意持有物（售出列表=持有物品，不限本城 goods）；任务=同阶段+下一阶段随机                                                       |
| 需求档位 | v9.7 正常主导（`demand-engine.js`）：非产出城市特产 hot ×(1+0.15/0.10) / normal / cool ×0.6 确定性轮换（16h），权重 [15/70/15] / [10/75/15]；趋势感知（涨价期不冷淡）；**基础物资/产出城恒 normal** |

> 注意：模拟为"全知择时"口径（假设玩家知道哪城哪日价格最优），**会系统性高估倒货**；真实玩家受价格可见性（仅本城可见）与信息滞后限制，实际倒货收益约为模拟的 1/3~1/5。

## 三、v9.7 做了什么（对照你的五条要求）

### 1. 缩短途特产跨城价差（近途无暴利）

- `SPECIAL_PRICE_TABLE` 重构：`rest` 兜底价 **产地×1.05~1.06**（原普遍 ×1.2~1.45），普通城市税后基本无利。
- 显式需求城溢价封顶 **×1.5**：近邻 ×1.15~1.3、中距 ×1.35~1.45、王都/边疆 ×1.5——"越远越贵"更陡且不失控。
- 例：橡木 3200 → 普通城 rest 3400（+6%，税后无利）/ 铁砧堡 3700（+16%）/ 王都 4600（+44%）/ 月影谷 4400（+38%）。

### 2. 热门削弱 + 正常主导

- 普通城热门加成 **0.20→0.10**（`HOT_BONUS_OTHER`），候选需求城 **0.20→0.15**。
- 三档权重：候选需求城 [15/70/15]、普通城 [10/75/15]——正常价占大多数（验证：jade 有效档位中 normal 64%）。
- 趋势感知保留：**涨价期冷淡概率归零**（验证：上涨趋势 70 次中冷淡 0 次）。

### 3. 王都特产

- 新增 **青瓷 celadon（产地 4000）/ 织锦 tapestry（产地 9000）**，王都 goods 5→7 种。
- 验证：`celadon@dawncapital=normal`（产出城）、`celadon@oaktown=hot`（参与三档）、`getHotBonus` 按城市类型区分（0.15/0.10）。
- 后期模拟最佳路线即"王都织锦 → 霜岭堡"，说明王都特产成为后期倒货抓手，任务/倒货比例回到 ×0.87。

### 4. 平衡定位

- 成长曲线：新手村任务主导（倒货中位数近乎无利）→ 初期/中期倒货渐强 → 后期两者相当（×0.87，接近目标 0.7~1.3 区间）。
- 模拟口径从"正利润日均"改为"**中位数日利润**"：突破极端日不再拉高均值，更贴近玩家常态。

### 5. 任务慢单概率

- 时效概率整体上调宽松档（common 0.38→0.46、传说 0.15→0.22）、下调加急档；宽松金币倍率 0.95→0.97。
- 效果：任务均时限 294→297s（新手村）/536→557s（中期），慢单增多鼓励顺路交单。
